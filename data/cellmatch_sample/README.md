This folder contains pre-processed data from the worm images of the dataset:

Citation
Li, Y., & Liu, X. (2023). Image stacks for full-body transcription factor expression atlas with completely resolved cell identities in C. elegans (Version 2) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.7628038

Which accompanied the publication:
Li, Y., Chen, S., Liu, W., Zhao, D., Gao, Y., Hu, S., ... & Liu, X. (2024). A full-body transcription factor expression atlas with completely resolved cell identities in C. elegans. Nature communications, 15(1), 358.

Images were pre-processed using the cellmatch software, we provide here a sample for testing functionality of the code.
